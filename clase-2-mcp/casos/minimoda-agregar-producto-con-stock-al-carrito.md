# MiniModa - Agregar producto con stock al carrito

- **Prioridad:** alta
- **Requisito:** El cliente puede agregar al carrito un producto disponible en stock, respetando la variante seleccionada y actualizando el carrito.

## Pasos
1. Abrir MiniModa y navegar hasta el catálogo de productos.
2. Seleccionar un producto que tenga stock disponible.
3. Elegir una variante requerida, como talle o color, si corresponde.
4. Indicar una cantidad menor o igual al stock disponible.
5. Presionar «Agregar al carrito».
6. Abrir el carrito y revisar el producto agregado.

## Datos
Producto: remera básica con stock disponible (por ejemplo, 5 unidades); variante: talle M, color negro; cantidad: 2.

## Resultado esperado
El producto se agrega al carrito con la variante y cantidad seleccionadas. El carrito muestra el nombre, variante, cantidad y precio correctos, y el subtotal se actualiza. No se muestra un error de falta de stock.
